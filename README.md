# WayUA

**WayUA** — адаптивний вебпрототип для планування мультимодальних подорожей з України до Європи. Проєкт показує, як можна поєднати залізничні та автобусні переїзди, пересадки в європейських транспортних хабах і подальший переліт в одному зрозумілому інтерфейсі.

Сервісна ідея зосереджена на безпечних стиковках: пасажир має бачити час на перетин кордону, трансфер до аеропорту та запас до наступного рейсу. Інтерфейс також демонструє маршрути, контрольні пункти, переваги сервісу та покрокове пояснення підходу до планування.

> **Статус:** навчальний фронтенд-прототип. Розклади, час очікування, маршрути, ціни та відгуки на сторінці є демонстраційними. Реального пошуку, перевірки черг, бронювання й підключення до API перевізників наразі немає.

## Можливості

- адаптивна навігація з мобільним меню;
- форма з полями міста відправлення, міста призначення та дати виїзду;
- кнопка обміну міст на ширших екранах;
- перемикач мовного інтерфейсу (англійська версія поки недоступна);
- демонстраційний блок часу очікування на пунктах пропуску;
- картки переваг і популярних маршрутів;
- візуальний таймлайн етапів поїздки з позначеним Smart Buffer;
- блоки з описом процесу, відгуками, закликом до дії та контактами.

## Технології

- HTML5 із семантичною розміткою;
- Tailwind CSS через CDN, з inline-конфігурацією кольорів і дизайн-токенів;
- Vanilla JavaScript для обміну містами та керування навігаційним меню;
- Google Fonts: Inter і Plus Jakarta Sans;
- SVG-ілюстрації та іконки.

Збірка та встановлення npm-залежностей не потрібні. Для навчального прототипу Tailwind CDN спрощує запуск; для production варто налаштувати Tailwind через збірку.

## Запуск проєкту

1. Завантажте або клонуйте репозиторій.
2. Відкрийте `index.html` у браузері або запустіть його через розширення на кшталт **Live Server** у VS Code.
3. Для завантаження Tailwind CSS і Google Fonts потрібне підключення до інтернету.

## Структура

```text
.
├── assets/
│   ├── icons/       # Логотип та SVG-іконки
│   └── image/       # Ілюстрації сторінки
├── css/
│   └── style.css    # Попередня таблиця стилів; сторінка її не підключає
├── index.html       # Розмітка, Tailwind-конфігурація та JavaScript
├── style_old.css    # Початкові стилі, збережені як довідкове джерело
└── PROMPT_LOG.md    # Журнал запитів і виконаних змін
```

## Інтерактивність

- **Обмін містами:** міняє значення полів «Звідки» і «Куди» та повідомляє про це через live region для скринрідерів. На вузьких екранах кнопка прихована.
- **Мобільне меню:** відкривається кнопкою-гамбургером, закривається після вибору посилання або натискання `Escape`; стан відображається в `aria-expanded`.
- **Форма маршруту:** зараз є демонстраційною HTML-формою й не виконує пошук маршрутів.

## Адаптивність і доступність

- макет адаптується до мобільних телефонів, планшетів і широких екранів;
- мобільна навігація переходить у горизонтальну від 1266 px;
- інтерактивні елементи мають видимі стани клавіатурного фокусу та достатню мінімальну висоту;
- форма має видимі підписи, а зображення й декоративні іконки мають відповідне текстове представлення або приховані від скринрідерів;
- на сторінці передбачено посилання для переходу до основного вмісту.

## Обмеження та подальший розвиток

Поточна версія не підключена до транспортних API та не перевіряє актуальність розкладів чи черг. Форма не будує маршрут, а часи, ціни та інші дані є прикладами для демонстрації інтерфейсу.

Можливі наступні кроки розвитку:

- визначити структуру даних міст, хабів і сегментів маршруту;
- реалізувати rule-based підбір варіантів і розрахунок безпечного буфера;
- додати сортування та порівняння маршрутів;
- підключити реальні дані перевізників і пунктів пропуску;
- додати збереження маршрутів та англомовну версію.
